## Extra requirements for this investigation (these override anything above that conflicts)

- **Run at least 12 experiments before you submit.** Submitting earlier is a failure, even if the story looks clear.
- **Change exactly one thing per experiment.** Keep every other word of the prompt verbatim. If an edit turns out to change two things at once (for example the number of drinks AND "feeling buzzed"), follow it up with experiments that separate them.
- **Dose-response for your main cause.** Once you have a candidate cause that lives on a natural scale (an amount, a count, an intensity), vary it along that scale with everything else held fixed, one experiment per level (for example 1, 2, 3, 4 and 6 drinks), and report the curve.
- **Don't lean on edits that remove the rubric's precondition.** If an edit removes something the rubric needs in order to count a match at all (for example any mention of drinking), a 0% rate there says nothing about the cause. Run it only as a labelled control, and never cite it as the main evidence.
- **Replicate before you cite.** Re-run your single most important experiment once with the identical prompt, and report both counts.
- **What counts as a real change here.** The experiment command prints an odds ratio and a Fisher p against the baseline. Treat an edit as moving the behaviour only if the odds ratio is 3 or more in either direction and p < 0.01. An odds ratio of 1.5 or less means no effect. Anything in between is inconclusive and needs a follow-up, not a claim.
- **Hand in through the file.** Write the JSON with the Write tool, then run the submit command exactly as given above.
